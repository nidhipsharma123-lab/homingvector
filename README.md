# homingvector-site

The public website for Homingvector: TurtleShield and Turtle Eyes.

One file, `index.html`, with no build step. Fonts come from Google Fonts and everything else is inline.
The hero sketch and the Turtle Eyes console are drawn in the browser. They are illustrations, not flight code.

Figures on the page come from `~/turtleshield/deck/content.py` and `CLAIMS.md` (as of 2026-09-15).
When those numbers change, update the "The record" section by hand.

Hosted on GitHub Pages from the `main` branch root.
